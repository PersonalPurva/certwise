How we check

Genuine?

  • Official verification link: real certificates can be checked on the issuer's own site (Credly, coursera.org/verify, nptel.ac.in, Microsoft Learn...). We check the link is on that official site.
  • Look-alike sites: a link that copies the issuer's name (e.g. "coursera-verify.com") is flagged as fake.
  • Certificate IDs: we check the ID format (e.g. Red Hat 123-456-789) and send you to the official page to confirm it.
  • Fake universities: the issuer is checked against UGC's list of 32 fake universities (February 2026).
  • No record at all: workshop and participation certificates have no official record - anyone can make one, so we say so.
