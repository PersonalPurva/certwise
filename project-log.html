HackathonShe Solves 3.0 (PCCOE ACM-W) · Theme "Time Stone - Ideas Beyond Time" · Track: Web & Software Development · Domain: Education
ProblemFirst-year engineering students don't know which job role to aim for or which certificates matter, so they collect many low-value ones - often pulled in by pressure-selling ads.
SolutionCertWise: a free web app - find your role, see what it needs, then check if a certificate (or an ad) is worth it.

Step 4 - What we built

1. Find my role

  • 8 questions; each answer adds points to one or more of 6 roles (Software Developer, Web Developer, Cloud/DevOps, Cybersecurity, Data Analyst, AI/ML).
  • Fit % = points the role got ÷ the most it could get. Shows the top 3 roles.
  • Role report: what the job is, college subjects that matter, skills to learn next, a mini project, demand in the market and fresher salary - each with a source link.

2. Check a certificate

  • Type any name - typos are fine ("secuirty plus" finds CompTIA Security+). We use edit distance (Levenshtein, dynamic programming).
  • 5 checks, 0-2 points each, shown in a table with the reason for every point.
  • Verdict: Worth it / Think twice / Skip, plus hard stops: Not yet (needs work experience), Not available (exam closed), Not for this role.
  • Better picks: recognised certificates for the same role that score "Worth it", cheapest first.

3. Check an ad

  • Paste any ad or WhatsApp message. 8 regex rules look for pressure tactics: urgency, tiny prices, "bonus worth ₹15,000", job guarantees, earning claims, speed promises, brand-name tools, crowd claims.
  • Each warning shows the exact phrase found and why it matters. The job-guarantee rule links to the CCPA guidelines on misleading ads.

70%+ = Worth it · 45-69% = Think twice · below 45% = Skip. A check that hasn't been scored yet is left out of the total.

Step 5 - Keeping data up to date without fake information

Decisions:

  • We first planned to collect job posts by hand. We dropped this: it is slow and goes out of date.
  • We wanted the data to stay current automatically, the way AI tools search the web, but with no made-up numbers.
  • We looked at RAG (retrieval-augmented generation) and decided it was not needed yet: CertWise asks fixed questions (salary for role X, price of certificate Y), so a scheduled, fact-checked refresh is cheaper and safer than generating answers for every visitor. RAG would make sense only if we add a free-text "Ask CertWise" chat.
  • To keep it free, the refresh can run with a free Google Gemini key. A paid Claude key is the other option.
Free mode (Gemini key)Paid mode (Claude key)
Where facts come fromOur script downloads the trusted pages already listed in our data (official exam pages, salary and hiring reports)Claude searches the web and reads pages, so it can find new sources
What it updatesPrices, exam status, salary, demand, skillsThe same, plus sources that say a certificate is in demand
Cost₹0 (free tier limits; the script waits between calls)Pay per use
Fact checkThe same in both: refresh/verify.js downloads the page itself and keeps a fact only if the quote is really on the page and every number in the fact is inside the quote. Failed facts are dropped and listed in refresh/report.json.
  1. Once a month (or on demand from the Actions tab), GitHub Actions runs refresh/refresh.mjs. A test run can be limited to a few topics.
  2. Verified facts go to data/live.js with the date. If a fact fails this month, last month's verified fact is kept.
  3. The app shows each live fact with its quote, link and check date. In free mode, a certificate's "in demand" check stays "not scored yet" instead of dropping to 0.

Status: built and tested. It needs one repository secret - GEMINI_API_KEY (free) or ANTHROPIC_API_KEY (paid). Until then the app says "not refreshed yet" and uses the hand-checked facts below.

Step 7 - Testing

  • 52 automated tests (npm test): search and typos, whole-word matching, every verdict type, demand scoring from live data, the fact checker, the free-mode helpers, alternatives, the ad scanner, that every role can win the quiz, and edit distance.
  • Practice refresh with a fake Gemini: the script downloaded the real AWS, Cisco and salary-report pages, kept a correct quote ("Cost 100 USD") and dropped a planted fake one ("quote not found on the page").
  • Browser checks on phone and laptop sizes, and on the live GitHub Pages site, with no console errors.
  • Bugs found and fixed:
    • The "earning claim" rule matched "Learn 20 tools" - now it needs "earn" plus a money amount.
    • The "brand tools" rule flagged official vendor ads - now it needs a "tools" context.
    • "AI tools workshop" wasn't found by search - added keywords to certificates.
    • NPTEL showed up as the "better pick" for every role - general certificates are now left out of role alternatives.
    • Added the "Not for this role" verdict so a cloud certificate isn't called "Worth it" for a data analyst.
  • Security: pasted text is escaped before it is shown (no XSS); no login and no personal data stored; API keys live only in GitHub secrets.
