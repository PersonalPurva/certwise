Key point: fake certificates are mostly an employer and university problem (forged degrees, fake universities). For students the bigger problem is value - a ₹9 workshop certificate is completely genuine but worth very little. So we check both.

3. Result

  • Genuine + market value, for any issuer, for Indian students, in one place: not found. The closest is Credly (verified badge + job data), but only for its own badges, with mostly U.S. data and no score.
  • Genuineness on its own is crowded (142 SIH teams, government systems, paid verification companies) - so our edge is the combination, any issuer (no partnership needed) and proof for every fact.

Limits: "not found" means our searches of the web, SIH lists, Devpost / Devfolio, GitHub and the Play Store didn't turn it up.

What we built

Input

  • Certificate name (typos are fine - edit distance, Levenshtein, dynamic programming).
  • Verification link or certificate ID - or the certificate file: PNG, JPG, WEBP or PDF, up to 5 MB. Images are scanned for a QR code (jsQR); PDFs for a QR code on the first 3 pages and for clickable or printed links (pdf.js). Other file types and bigger files are refused with a clear message. Everything runs in the browser - the file is never uploaded.
  • Optional: the college / institute that issued it.

Answer 1 - Is it genuine?

  • Official verification link - the link is on the issuer's own verification site (domain + path checked).
  • Look-alike website - the link copies the issuer's name or is a small typo of it (coursera-verify.com, credlly.com).
  • ID looks right / doesn't match the format - e.g. Red Hat 123-456-789, then the official page to confirm.
  • Can't be verified - certificate types with no official record.
  • Fake university - issuer matched against UGC's list of 32 (typos allowed).
  • We never say "100% genuine" - the last step is always the issuer's own page, linked with one button.

Answer 2 - What is it worth?

Check2 points1 point0 points
Recognition (who gives it)Company / body that owns the field, or an IITLearning platformUnknown training company
Proof of skill (how you earn it)Supervised examOnline tests / projectsAttendance
Job demandVerified sources, or its jobs are "in demand" in cited reportsOne source / IT under pressure / depends on courseNot a credential employers ask for

70%+ High · 45-69% Medium · below 45% Low. Also shown: price (with proof), fresher salary of the jobs it leads to (with sources), warnings (exam closed, needs work experience) and higher-value certificates in the same field. If the certificate looks fake, its market value is 0%.

A GitHub Actions job runs it on the 1st of every month. It needs one repository secret - GEMINI_API_KEY (free) or ANTHROPIC_API_KEY. Until then the app uses hand-checked facts, each with a proof link.

Testing

  • 79 automated tests (npm test): search and typos, every genuineness result (official link, wrong page, look-alike, typo domain, wrong issuer, ID formats, no record, fake university with typos, real university not flagged), the upload rules (allowed types, 5 MB limit, empty file), choosing the right link inside a PDF, market value scores, higher-value picks, the fact checker and the free-refresh helpers.
  • Browser checks of all five examples at laptop and phone widths, with no console errors.
  • Upload checks with sample files in tests/: a PNG with a QR code, a PDF with a QR code and a PDF with only a printed link all gave "Official verification link"; a 6 MB file, a .docx file and a damaged PDF were each refused with the right message.
  • Fixed while testing: "Commercial University Ltd." wasn't matched because of the full stop; a fake certificate showed a high market value - it now shows 0% if fake; PDF pages didn't finish drawing when the browser tab was in the background - the page is now drawn in one go, with a 6-second limit.
  • The deck passed file validation and every slide was checked as an image.

Round 1 presentation

  • 6 slides in the organisers' template, SIH-deck style: Title · Idea · Technical approach · Feasibility · Impact · Research and references.
  • Every number has a reference [1]-[9]; the proof table with the exact source words is in the slide notes file.

HTML, CSS, JavaScript (no framework, no backend) · jsQR for reading QR codes and pdf.js for reading PDFs, both in the browser · Node.js for tests and the refresh script · Gemini (free) or Claude API for the monthly refresh · GitHub Actions · GitHub Pages (₹0 server cost).
